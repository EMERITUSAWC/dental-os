The basics

The API lives at {{ base }}. Send your key in a header on every request. Send and receive JSON. A key sees only its own clinic.

curl {{ base }}/patients?limit=10 \
  -H "Authorization: Bearer YOUR_KEY"
  • Lists return {"data": [...], "next_after": 123}. To get the next page, send ?after=123. next_after is null on the last page. limit is up to 200.
  • Errors return {"error": {"code": "...", "message": "..."}} with the usual status: 400 bad request, 401 no or wrong key, 403 read-only key, 404 not found, 409 cannot be done as asked, 422 details need fixing, 429 too many requests.
  • Each key may make 300 requests a minute.
  • Money is in the smallest unit of the clinic's currency (pesewas, cents, pence), in fields ending _p. Appointment times are the clinic's own local time. created_at and updated_at are UTC.
  • Medical history, clinical notes, files and message text are never available through the API or webhooks.

Writing (read and write keys only)

POST /patientsfirst_name, last_name, phone are needed. Also dob, gender, email, address, preferred_contact, agreed_to_appointment_messages, agreed_to_offers, notes. A likely duplicate returns 409 unless you send "allow_duplicate": true.
PATCH /patients/{id}Send only the fields to change.
POST /appointmentspatient_id, provider_id, start_at ("2026-11-30 14:30"). Optional chair_id, duration_min (15, 30, 45, 60, 90, 120), category, notes. The diary's rules apply: opening hours, no double booking.
POST /appointments/{id}/status{"status": "complete"} or {"status": "broken", "break_reason": "missed"} (or "cancelled").

Webhooks

Add an https address under API and webhooks. When a chosen event happens we send it a POST with a JSON body:

{"id": "evt_...", "event": "patient.created", "clinic_id": 1, "created": "2026-11-30T14:05:00Z", "data": { ... }}

Check the signature. Each request has X-DentalOS-Signature: t=TIMESTAMP,v1=HEX. Compute HMAC-SHA256 of TIMESTAMP + "." + raw body with your signing secret, compare to v1, and reject requests whose timestamp is more than 5 minutes old.

import hmac, hashlib, time

def is_genuine(secret, header, raw_body):
    parts = dict(p.split("=", 1) for p in header.split(","))
    if abs(time.time() - int(parts["t"])) > 300:
        return False
    expected = hmac.new(secret.encode(), parts["t"].encode() + b"." + raw_body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, parts["v1"])
  • Answer with any 2xx status within 6 seconds. Anything else counts as a failure.
  • Failures are retried after 1 minute, 5 minutes, 30 minutes, 2 hours and 12 hours. Then it gives up, and you can press "Try again" on the page.
  • A message can arrive more than once. Use the id to ignore ones you have already handled.
  • Redirects are not followed, and addresses on private networks are refused.
